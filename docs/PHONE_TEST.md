# Phone test checklist

Things built since 2026-10-21 that no one has seen on a real phone. Run it in one sitting (about 20 minutes), landscape, on https://spaceblast.vercel.app.
Tick what works. For anything wrong, write one line under "Found" (screen, what you did, what happened) and tell the design chat; it becomes a Ready item.

## Menus and screens
- [ ] Menu: icon + label items, Back pinned top-left on every page, black micro-fade between screens
- [ ] Settings and How to Play open as a centred card; ‹ › selectors work by touch
- [ ] Level card: one centred box, launch button reachable
- [ ] HUD: Sound / Pause / Full screen grouped top-right, not over the hearts; notch does not cut anything
- [ ] HUD: CHARGE button looks like a solid plasma charge; power-up icons readable; Bosco portrait in the avatar
- [ ] Pause during 3-2-1-BLAST!: nothing draws over the pause card

## Play feel (Story level 1-3, then a Battle vs Bot round)
- [ ] 3-2-1-BLAST! count, red damage vignette, vibration on Charge and on hit (Android)
- [ ] Low-poly astronaut: run cycle, arms forward on Charge, frame rate stays smooth
- [ ] Oxygen Vest bubble pulses; Speed Boost trail appears when moving
- [ ] Touch controls stay in the side gutters; buttons feel at least finger-sized

## Online (two phones, or phone + PC)
- [ ] Lobby fits sideways with no scrolling; colour strip scrolls by swipe
- [ ] Invite button opens the share sheet; the link opens Multiplayer with the code filled in
- [ ] Astronauts glide, no shaking; your own moves respond instantly
- [ ] Turn Wi-Fi off for 5 s mid-round: "Reconnecting…" shows, then the round continues

## Offline
- [ ] Open the game once, then airplane mode: Story and Battle vs Bot still open
- [ ] Installed to home screen (iOS): opens offline too
